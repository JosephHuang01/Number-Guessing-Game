# Number Guessing Game

This project is a simple web-based number guessing game built as part of my practice developing Python and AI-assisted application skills. I use this project to strengthen my understanding of programming fundamentals, Python development workflows, and how to effectively leverage AI instructions and tools to build practical software.

The goal is not just to create a game, but to practice designing, iterating, and improving a web app in a structured way while learning how to collaborate with AI systems to generate code, troubleshoot issues, and refine solutions. I am intentionally using AI as a learning and productivity tool to better understand how modern development workflows can support faster iteration and cleaner problem solving.

I’m sharing this project as part of my portfolio and learning journey.
## Project Overview

A browser-based number guessing game where the player tries to guess a random number within a limited number of attempts.

## Features

- Randomized target number
- Guess feedback for too high or too low
- Win/lose state tracking
- Simple browser UI
